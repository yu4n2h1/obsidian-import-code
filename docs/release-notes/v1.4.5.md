# Release Note — v1.4.5

**Import Code** for Obsidian

## ✨ 新功能

### HTML CSS 选择器多匹配提取

`![[file.html@选择器]]` 现在采用 `querySelectorAll` 语义——选择器命中**多个**元素时，全部按文档顺序提取并拼接展示，不再只显示第一个。

```markdown
![[quiz.html@div.des]]        <!-- 提取所有 class="des" 的 div，逐段拼接展示 -->
![[quiz.html@div.des,div.des_2]]   <!-- 混合选择器：两类元素全部选出 -->
```

- 各匹配片段之间以空行分隔
- 行号保留源文件**真实行号**（多片段下行号跳跃显示，如 `4, 5, 6, 8, 9`），可据此定位回源文件
- 单匹配选择器行为与旧版完全一致
- 搭配 `#` 高亮：`![[file.html@div.des#3-5]]` 高亮拼接后内容的第 3–5 行

## 🐛 修复

- **HTML 提取的闭标签丢失**——上个版本引入的 off-by-one：每个提取区间少切最后一行（`</div>` 丢失）且行号偏移 1，已修复
- **同 class 多元素只显示第一个**——多个相同签名的元素（如都是 `div.des`）定位到同一开标签行导致区间重合，现在逐个消费开标签行、区间正确分离
- **分屏下实时预览 embed 解析错位**——Live Preview 现在从 embed 所在的 MarkdownView 取 sourcePath，而非焦点所在 pane（分屏场景下相对链接解析错误）
- **wrap + 行号布局**——长行换行开启时行号与代码不再混排，代码不越过行号列、分隔竖线连续
- **聚焦态行号样式**——点击放大代码后行号 gutter 样式保持，不再与代码贴混
- **符号提取误判**——`extractBlock` 现在感知字符串字面量与行注释，`console.log("{")` 之类不再截断代码块
- **并发 embed 内容串扰**——同一文件以不同 symbol 嵌入多处时，请求去重 key 已包含 symbol，不再互相覆盖
- **GitLab token 空值守卫 / 上传源字段统一**（`url`/`path`）等配置健壮性问题

## 🔧 内部

- ESLint 完全归零：补齐 Obsidian 全局 DOM helper 声明（`createDiv`/`createSpan`/`createEl`）与 vitest 配置解析
- 测试覆盖扩充至 **245 例**（新增 HTML extractor 回归测试 11 例，happy-dom 提供 DOMParser 环境），并新增 Obsidian CLI 驱动的 E2E 测试（本地 embed 全套）
- 架构文档拆分为总览 + 分层子目录（`docs/architecture/`），与代码同步更新
